# Asset provenance

- `dragon-landscape.png`: AI-generated fantasy illustration created for Haru Unabara in this session, 2026-10-15. No third-party photograph or existing artist's work was supplied as a reference. This is not a claim of exclusive copyright or human authorship.
- `hero.jpg`: the illustration resized with Cormorant Garamond lettering; generated by `scripts/build_assets.py`.
- `hero-phrases.gif`: original phrase-strip composition generated by the same script. The dragon illustration itself does not move.
- `fonts/CormorantGaramond.ttf`: Cormorant Garamond variable font from `google/fonts`, blob `d992a83ce525c330fad3a19087746bcb2dc038ee`. SIL Open Font License 1.1 in `fonts/OFL.txt`.
- `logos/*.svg`: Simple Icons paths downloaded from the `simple-icons/simple-icons` GitHub repository on 2026-10-15, with a cool silver fill added. License and trademark caveats are in `logos/LICENSE.md`. Icons identify technology use, not endorsement. Original aspect ratios are preserved.
- `languages.svg`: original chart built from public GitHub API byte counts. Source data and timestamp: `../docs/languages.json`.

Regenerate the artwork and GIF with Python, Pillow 12.3.0, and `python scripts/build_assets.py`. Refresh the language snapshot with an authenticated GitHub CLI and `python scripts/update_languages.py`; review the README's date and textual percentage fallback after refreshing. No external image service is required at viewing time.
