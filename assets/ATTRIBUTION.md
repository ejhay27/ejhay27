# Asset provenance

- `hero-title-card.gif`: original animated-typography composition generated by `scripts/build_assets.py` (Pillow + numpy). No photograph, illustration, or background artwork is used — only lettering, hairline rules, and diamond ornaments over a midnight-navy gradient. Lettering set in Cormorant Garamond.
- `fonts/CormorantGaramond.ttf`: Cormorant Garamond variable font from `google/fonts`, blob `d992a83ce525c330fad3a19087746bcb2dc038ee`. SIL Open Font License 1.1 in `fonts/OFL.txt`.
- `logos/*.svg`: brand glyph paths from Simple Icons (CC0), fetched from the npm registry on 2026-10-15 — current marks from **v16.35.0**; the Adobe Photoshop/Illustrator/Premiere Pro/After Effects marks, the Visual Studio Code mark, and the classic CSS3 badge from archived **v12.4.0** (those were removed from v13 onward). Each glyph is placed on a midnight-navy tile by `scripts/fetch_logos.py`; license and trademark notes in `logos/LICENSE.md`. Dark glyphs (GitHub, IntelliJ IDEA) are lightened toward silver for visibility on the navy field. Icons identify tool use, not endorsement. Original aspect ratios are preserved.
- `logos/alight-motion.svg`: original "AM" lettermark tile. Alight Motion's brand glyph is not distributed by Simple Icons or any comparable open set; the lettermark is a typographic placeholder, not an imitation of the app icon, and the README says so.
- `languages.svg`: original chart built from public GitHub API byte counts. Source data and timestamp: `../docs/languages.json`.
- Removed in the 2026-10-15 redesign: `dragon-landscape.png` (AI-generated fantasy illustration), `hero.jpg` (banner derived from it), and `hero-phrases.gif` (the narrow strip superseded by the larger title card). They remain available in git history only; no current file references them.

Regenerate the tiles and the animated card with Python, Pillow, numpy, and `python scripts/fetch_logos.py && python scripts/build_assets.py`. Refresh the language snapshot with an authenticated GitHub CLI and `python scripts/update_languages.py`; review the README's date and textual percentages after refreshing. No external image service is required at viewing time.
